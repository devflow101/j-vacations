# Image Specifications for J-Vacations

## Travel Packages Images
**Path**: `/public/images/packages/`

**Required Files**:
- `maldives.jpg` - Maldives package image
- `europe.jpg` - European Adventure package image
- `safari.jpg` - Safari Experience package image

**Dimensions**: 800 × 400 pixels (2:1 aspect ratio)
**Format**: JPG or WEBP (recommended)
**Size**: Keep under 200KB for good performance

These images appear in the Travel Packages section on the homepage with a fixed height of 192px (h-48) and full width.

## Special Offers Images
**Path**: `/public/images/offers/`

**Required Files**:
- `summer-discount.jpg` - Early Summer Discount offer
- `family-package.jpg` - Family Package Deal offer
- `honeymoon-special.jpg` - Honeymoon Special offer

**Dimensions**: 800 × 600 pixels (4:3 aspect ratio)
**Format**: JPG or WEBP (recommended)
**Size**: Keep under 200KB for good performance

These images appear in the Special Offers section on the homepage with a fixed height of 192px (h-48) and full width.

## Tips for Best Results
1. Use high-quality, professional travel images
2. Ensure good contrast for text visibility
3. Images should be relevant to the package/offer
4. Optimize images for web using tools like TinyPNG or ImageOptim
5. Consider using the WEBP format for better compression and quality
